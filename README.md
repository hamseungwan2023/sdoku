# 🧩 Sudoku Web App

Vite와 TypeScript를 기반으로 제작된 깔끔하고 반응형인 웹 스도쿠(Sudoku) 게임입니다.

---

## 🚀 주요 기능 (Features)

- **직관적인 UI/UX**: 웹 브라우저에서 간편하게 즐길 수 있는 깔끔한 스도쿠 인터페이스
- **난이도별 플레이**: 플레이어의 실력에 맞춘 난이도 선택 기능
- **실시간 유효성 검사**: 행, 열, 3x3 박스 내 중복 숫자 실시간 체크
- **게임 편의 기능**: 타이머 및 기록 측정 기능 지원
- **반응형 디자인**: PC와 모바일 환경 모두에서 쾌적하게 플레이 가능

---

## 🛠️ 기술 스택 (Tech Stack)

- **Language**: TypeScript, HTML5, CSS3
- **Build Tool**: Vite
- **Library**: React / DOM API
